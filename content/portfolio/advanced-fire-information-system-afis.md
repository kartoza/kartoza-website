## Overview

We built the new AFIS web front end. AFIS is a system for automatic detection of fires in the SADC region using MODIS and other satellite data. The fire detection infrastructure was developed internally by the CSIR/Meraka and we were tasked with the creation of a rich, user friendly web mapping interface for this data. The development of the AFIS front-end has since continued internally after we completed the initial development.
