## Overview

Kartoza developed a web application for the planning and monitoring of OpenStreetMap field mapping campaigns. Kartoza helped to extend the project to include a campaign management application, which allows field campaigns to be tracked and their quality measured. Campaign managers utilise this tool to set up new and review ongoing and completed campaigns. Mappers can find nearby field campaigns for participation, resulting in improved data collection standards and project management.
