## Course Overview

This intensive 5-day course gives participants the skills and knowledge to plan, establish, and manage a production-grade open source GIS stack. Using FOSS tools — PostgreSQL/PostGIS, GeoServer, QGIS Server, and GeoNode — you will learn how to build an enterprise spatial data infrastructure that is world-class, cost-effective, and fully supported by active open source communities.

The course moves from foundational concepts through to hands-on system administration. Participants leave with a working understanding of how all components connect, practical configuration experience, and the ability to troubleshoot and maintain the system after the course.

## Course Modules

<div class="course-modules">
  <details class="course-module">
    <summary><span class="course-module-number">1</span><strong>
Enterprise GIS Concepts & FOSS Stack Overview</strong><span class="course-module-time">Day 1</span></summary>
    <p>Introduction to enterprise GIS architecture — what makes a system "enterprise-grade," how FOSS tools compare to proprietary alternatives, and how PostGIS, GeoServer, QGIS Server, and GeoNode fit together. You'll map out the architecture you'll be building across the five days.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">2</span><strong>Spatial Database Setup with PostGIS</strong><span class="course-module-time">Day 2</span></summary>
    <p>Install and configure PostgreSQL and PostGIS. Design and create spatial database schemas suitable for an enterprise environment. Import data from shapefiles, CSVs, and other sources. Write basic spatial SQL queries to validate your setup.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">3</span><strong>GeoServer Installation & OGC Service Publishing</strong><span class="course-module-time">Day 3</span></summary>
    <p>Install GeoServer and connect it to your PostGIS database. Publish WMS, WFS, and WCS services. Configure layer styles using SLD. Set up workspaces, stores, and layers. Manage users and security roles for controlled access.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">4</span><strong>Web Clients, QGIS Integration & GeoNode</strong><span class="course-module-time">Day 4</span></summary>
    <p>Compose and serve web maps. Connect your GeoServer services to QGIS for desktop access. Set up GeoNode as a spatial data portal for metadata, discovery, and sharing. Understand how end-users interact with the stack from both desktop and browser.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">5</span><strong>
Administration, Troubleshooting & Production Readiness</strong><span class="course-module-time">Day 5</span></summary>
    <p>System administration best practices: monitoring, backups, log management, and performance tuning. Troubleshoot common failure points across the stack. Review architectural considerations for corporate IT environments including firewalls, reverse proxies, and SSL. Conclude with a practical system review exercise.</p>
  </details>
</div>

### Prerequisites

- Experienced GIS user — this course is not suitable for beginners
- System administration or IT background helpful (Linux or Windows server experience)
- Basic familiarity with databases and/or web technologies is an advantage
- Laptop running Ubuntu Linux or Windows (Ubuntu strongly preferred)
