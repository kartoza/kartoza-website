## Course Overview

This hands-on course introduces participants to spatial database concepts and practices using PostgreSQL and PostGIS — the industry-leading open source spatial database solution. You'll learn to design efficient spatial database schemas, write spatial SQL queries, and connect your database to QGIS and other tools.

The course combines theoretical concepts with extensive hands-on practice, ensuring participants leave with working SQL skills and the ability to manage spatial data at scale. Available as a 2-day instructor-led course or as a self-paced option you can work through at your own pace.

## Course Modules

<div class="course-modules">
  <details class="course-module">
    <summary><span class="course-module-number">0</span><strong>Course Orientation &amp; Setup</strong><span class="course-module-time">Before you begin</span></summary>
    <p>Get PostgreSQL and PostGIS installed on your machine and connect to the course database. You'll be introduced to the course structure, the Communication Hub, and the sample datasets used throughout the exercises. By the end of this module you'll have a working geospatial RDBMS ready for the course.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">1</span><strong>Introduction to PostgreSQL &amp; PostGIS</strong><span class="course-module-time">Day 1 · Morning</span></summary>
    <p>Understand the geospatial RDBMS architecture and how PostGIS extends PostgreSQL for geographic data. You'll explore the PostGIS geometry types, spatial reference systems, and the key functions that make spatial SQL possible. By the end of this module you'll know why a spatial database outperforms shapefile workflows for real-world data management.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">2</span><strong>SQL Fundamentals for Spatial Data</strong><span class="course-module-time">Day 1 · Afternoon</span></summary>
    <p>Build confidence writing SQL from scratch — tables, fields, primary and foreign keys, and full CRUD operations (CREATE, READ, UPDATE, DELETE). No prior database experience required. You'll write your first spatial queries and learn the conventions that make SQL readable and maintainable in a team environment.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">3</span><strong>Spatial Queries &amp; PostGIS Functions</strong><span class="course-module-time">Day 2 · Morning</span></summary>
    <p>Insert and manipulate geometries, run spatial queries, and apply PostGIS functions and operators. You'll work with ST_Intersects, ST_Buffer, ST_Distance, ST_Area, coordinate transformations, and spatial joins. By the end of this module you'll be comfortable answering real-world "where" questions using SQL against a live spatial database.</p>
  </details>
  <details class="course-module">
    <summary><span class="course-module-number">4</span><strong>QGIS Integration &amp; Enterprise Workflows</strong><span class="course-module-time">Day 2 · Afternoon</span></summary>
    <p>Connect your PostGIS database to QGIS using DB Manager. Import and export spatial data, visualise query results on a map, and explore how PostGIS fits into a FOSS enterprise GIS stack alongside GeoServer and GeoNode. The session closes with a bring-your-own-data exercise where you apply the day's skills to a real dataset of your choice.</p>
  </details>
</div>
