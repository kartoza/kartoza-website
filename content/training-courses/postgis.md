## Course Overview

This hands-on course introduces participants to spatial database concepts and practices using PostgreSQL and PostGIS — the industry-leading open source spatial database solution. You'll learn to design efficient spatial database schemas, write spatial SQL queries, and connect your database to QGIS and other tools.

The course combines theoretical concepts with extensive hands-on practice, ensuring participants leave with working SQL skills and the ability to manage spatial data at scale. Available as a 2-day instructor-led course or as a self-paced option you can work through at your own pace.

## Key Learning Outcomes

- General database concepts, including what is a relational database?
- SQL basics including syntax, structure, standards and conventions
- Connecting to a database
- Building queries including Commands, functions, operators, etc
- Resources - documentation and tutorials

## Who Should Attend

This course is ideal for:

- GIS professionals moving to database-driven workflows
- Database administrators managing spatial data
- Developers building spatial applications
- IT staff responsible for GIS infrastructure
- Analysts working with large spatial datasets

Participants should have basic knowledge of SQL and relational databases.

## Prerequisites

- Basic familiarity with GIS concepts (layers, feature types, projections)
- Basic computer literacy — no prior SQL or database experience required
- Personal laptop with two screens (recommended for online sessions)
- Interest in spatial data management and database-driven workflows
