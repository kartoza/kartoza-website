QGIS Temporal Dataset Support and Time-Slider Development
{{< /block >}}

## Overview

We developed the infrastructure in QGIS API to support temporal datasets with a reference

implementation for WMS-T client support. The API can be used to support other services in the future

such as time based WFS, WCS, vector data with time etc. We also developed a visualisation time-

slider control for QGIS that allows you to ‘play’ through the time series of the time-based layers in

your project.
